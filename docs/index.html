連接現場 ESP32

iPhone 請使用 Bluefy 開啟本頁；Android 可使用支援網頁藍牙的 Chrome。

查看連接步驟與下載方式

請使用 Bluefy 開啟本網站，並允許藍牙權限。一般 Safari／iPhone Chrome 無法直接使用這裡的網頁藍牙。

  1. 安裝 Bluefy，將本頁網址複製並貼到 Bluefy 網址列。即使 Bluefy 介面是英文，本網站仍顯示繁體中文。
  2. 在本頁按「連接 ESP32」，選擇 Ferris-Admin-Jog，不需先到手機藍牙設定配對。
  3. 若掃 QR Code 後進入 Safari，請複製網址，再到 Bluefy 開啟。

下載 Bluefy（App Store）官方連接說明

Android 請用支援網頁藍牙的 Chrome。手機需在 ESP32 附近；連線不等於已啟動馬達。

開啟裝置藍牙，按下「連接 ESP32」，選擇 Ferris-Admin-Jog。

祭拜音樂

  1. 開啟功放板，在手機的「設定 → 藍牙」選擇 Shaibang 並連線。
  2. 用手機的音樂 App 播放大悲咒或你想聽的音樂。播放、暫停和音量都在手機上操作。
  3. 若聲音仍從手機播出，請在手機的媒體音訊輸出選擇 Shaibang。

功放板和 ESP32 分開連線。這裡的「連接 ESP32」只用於連接控制板。
